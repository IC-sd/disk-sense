# Windows 独立环境验收

本清单区分自动回归和需要系统快照的验收。测试通过不等于安装升级、服务重启或真实系统维护已验证。

## 环境与证据

使用可回滚的 Windows 10 和 Windows 11 x64 虚拟机，各准备普通用户、管理员、NTFS C/D 卷。记录系统版本、提交 SHA、安装包 SHA256、安装版本、用户权限和数据目录。每项记录实际步骤、预期/实际结果、脱敏日志与截图；系统变化项目完成后回滚快照。

## 当前自动门槛

- `pnpm validate`：Vue 类型检查、四个关键后端边界模块的 checkJs、测试、全部 CJS 语法与构建。
- CI：开发冒烟、解包程序构建、ASAR/Fuses 检查、真实打包搜索冒烟。本地记录时新增 CI 尚未在远端执行；最新状态见 [GitHub Actions](https://github.com/IC-sd/disk-sense/actions)。
- 本地测试覆盖：旧快照并发读取、提交后查询刷新、查询取消与临时表释放、磁盘会话完整分页和四种排序、迁移检查点关闭读库并恢复。
- 本地合成索引：`pnpm benchmark:bounded-search 100000`，最多可指定 1000000。只创建、删除工作区下专用夹具；不读取用户索引。输出不是 GUI 首屏指标或内存峰值。

## 已准备的独立验收流程

“独立环境”指一台用完可以丢弃或恢复的临时 Windows 测试机。安装、卸载和服务测试不能为了补齐验收记录而直接在日常电脑上执行。

仓库新增 `Disposable Windows acceptance` 工作流（`.github/workflows/windows-acceptance.yml`），只接受手动触发，没有 push/pull_request 触发器。它在 GitHub 提供的临时 Windows 机器内完成：

1. 使用冻结依赖构建本次 NSIS 安装包，不发布 release。
2. 从项目官方 release 下载基线安装包（默认 beta.7），核对同一 release 中公布的 SHA256。
3. 安装基线到专用目录，通过已安装程序的真实 preload/IPC 写入主题、收藏、排除项和一个虚构的加密 API 密钥；不调用外部 AI。
4. 在同一目录升级到本次构建，核对版本与上述数据，验证虚构操作历史可读、密钥仍可解密且没有明文写入状态和日志。
5. 卸载并逐文件核对状态校验和，安装到不同目录再次验证数据，然后卸载专用测试安装。
6. 可选地安装只读搜索服务，核对 LocalSystem 身份、并发连接、错误令牌拒绝、禁止 shutdown RPC、服务重启后的重连及卸载。它不重启 Windows、不执行 DISM/ResetBase 等维护操作。
7. 无论通过或失败都上传 JSON 验收证据，报告明确保留 `standardUserAndUacFlowVerified=false`、`fullWindowsRebootVerified=false` 等未覆盖项。

本地记录时此工作流尚未运行；准备好自动化流程或推送源码不等于这些真实系统操作已经验收通过。GitHub 的临时 Windows runner 也不能替代 Windows 10/11 普通用户、UAC 和完整系统重启的专门测试。

本地查看计划（不安装、不修改系统）：

```powershell
pwsh -NoProfile -File scripts/verify-windows-installation.ps1
```

只有在可丢弃的 Windows 虚拟测试机内部，显式设置 `DISK_SENSE_DISPOSABLE_VM=1`，并且硬件型号能确认是虚拟机时，才可以添加 `-Execute`、基线安装包及其 SHA256、当前安装包等参数运行。脚本会拒绝物理宿主、已有 Disk Sense 数据的账户、校验和不符的基线和不受控的证据目录。服务生命周期步骤另需临时测试机内的管理员令牌；普通用户/UAC 交互仍保留人工验收。

2026-10-29 本机只读探查：Windows 11 家庭中文版，LENOVO 83QG，未发现可调用的 Windows Sandbox、Hyper-V PowerShell、VMware 或 VirtualBox 管理工具。虽然检测到 hypervisor，但这不足以证明有独立 Windows 测试机。本机实际完成了计划模式、物理宿主拒绝执行、脚本语法和隔离门槛回归测试；没有执行安装、卸载、服务变更或重启。原始探查与拒绝记录保存在被 Git 忽略的 `work/windows-acceptance-*`。

## 需要独立执行的项目

| 项目 | 操作 | 通过条件 | 当前状态 |
| --- | --- | --- | --- |
| 新安装 | 普通用户安装到自定义目录，启动、搜索后退出重启 | 不要求常驻管理员；设置与索引保留，程序能再次启动 | 待 VM 验收 |
| 跨版本升级 | 安装 beta.7，写入收藏、AI 配置和操作记录，再升级本次构建 | 数据可读，凭据不出现在日志；索引兼容或明确重建 | 待 VM 验收 |
| 卸载与重装 | 卸载后检查保留的数据，再安装到不同位置 | 不删除需保留的数据，重装行为符合说明 | 待 VM 验收 |
| 搜索服务 | 授权安装、拒绝 UAC、更新、停止、重启系统、卸载 | 普通 UI 与服务权限分离；失败可解释；重启可恢复游标 | 待 VM 验收 |
| USN 断档 | 在专用卷使游标过期并制造大量改名/移动/删除 | 保留可用旧索引，明确重建，不发布半成品 | 待 VM 验收 |
| 云文件 | OneDrive 占位、已下载、失去连接三种状态 | 有界读取；占用不确定时标记部分结果；不会把大小当可释放量 | 待 VM 验收 |
| 数据迁移 | C 到 D、目标磁盘不足、锁定交接文件、中途关机、目标盘不可用 | 保留一致的源数据；交接成功后启用目标；失败不打开混合数据 | 待 VM 验收 |
| 清理中断 | 只扫描专用夹具，在操作尝试后终止程序并重启 | 未确认结果进入人工核对，不自动重试；原始证据保留 | 待 VM 验收 |
| 系统维护 | 在快照内核对确认词、权限、取消、失败、重启提示及 ResetBase | 仅执行固定官方命令；不可逆状态明确，结果可追溯 | 待 VM 验收 |

不得将夹具故障注入测试记作真实磁盘不足、断电或系统重启验收，也不得在日常主机上为了补齐清单执行不可逆维护。
